# Notas de Producto

> **Dónde está:** Productos → **Notas de Producto**
> **Para qué sirve:** comentarios predefinidos que se agregan a **un producto puntual**, con un click.
> **Quién lo usa:** mozos, cocina, administradores.

---

## 🧭 Antes de entrar acá

Esta pantalla se confunde fácil con [Notas de Comanda](/user-guide/notas-de-comanda), porque son visualmente casi idénticas. La diferencia es el **alcance**:

| | Notas de Producto | Notas de Comanda |
|---|---|---|
| Aplica a | **Un solo producto** dentro del pedido | **Toda la comanda / el pedido** |

**Ejemplo real:** piden 2 jugos Baggio en la misma comanda → eso lleva una nota de comanda **"sabor: naranja"** (todo el pedido). Pero un cliente pide que **uno** de esos 2 jugos sea con hielo → esa es una nota de producto **"con hielo"**, porque es puntual a ese ítem.

El propio sistema lo explica así:

> *"Las observaciones de productos son comentarios predefinidos que se cargan para no tener que escribir manualmente. Con un solo click, se pueden agregar estas observaciones. Por ejemplo, las más comunes pueden ser 'sin sal', o algún detalle específico del pedido como 'marchar en 10 minutos'. Son configurables por el comercio — algunos las usan para pedir HIELO, ya que no se cobra y se agrega como una observación del producto en la comanda."*

## ▶️ Cómo se usa

### Crear una nota de producto

1. Tocá **+ Crear Observación**.
2. Escribí el texto (ej. "Sin cebolla", "Bien cocido").
3. Guardá.

Queda disponible para agregar con un click sobre un producto puntual del pedido.

---

## 🔗 Cómo se conecta con el resto

**Alimenta a:**
- Salón de Ventas / Comandero → aparece como opción de un click sobre un ítem del pedido

## ❓ Preguntas frecuentes

**¿Una nota de producto se cobra?**
No necesariamente. El propio sistema da el ejemplo del hielo: es una observación que no se cobra, solo informa una preferencia. Si necesitás cobrar un agregado, esa es tarea de una [variante](/user-guide/variantes-grupo-sabores) con su propio precio, no de una nota.

**¿Cómo sé si debería crear una nota de producto o una de comanda?**
Preguntate si el comentario aplica a **un ítem específico** o a **todo el pedido**. Si dudás, mirá el ejemplo de los jugos Baggio más arriba.
